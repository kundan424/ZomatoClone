# Zomato Clone

A highly scalable, secure, and event-driven food delivery API built with Spring Boot. This backend handles the complete lifecycle of a food order, including stateless JWT authentication, Redis-backed distributed locking for inventory management, and asynchronous Stripe webhook processing.

## ⚙️ Tech Stack

* **Core:** Java 17+, Spring Boot 4.xx
* **Data & Caching:** PostgreSQL, Redis, Spring Data JPA
* **Security:** Spring Security, stateless JWT
* **Integrations:** Stripe Payment Gateway, Stripe Webhooks
* **DevOps:** Docker, Docker Compose
